# Screenshot Tugas 10

Semua gambar sudah tersedia di folder ini dan ditampilkan di README utama
bagian Screenshot.

1. `01-postgres-berjalan.png` - container `tpwb-postgres` aktif dengan port
   `5433->5432`.
2. `02-migrasi-prisma.png` - status migrasi Prisma dan folder migrasi.
3. `03-tabel-students.png` - struktur dan isi tabel `students`.
4. `04-uji-get-all.png` - GET semua data, status 200, total 5.
5. `05-uji-create.png` - POST data baru beserta request body, status 201.
6. `06-uji-update.png` - PUT data, status 200, field yang diubah terlihat.
7. `07-uji-delete.png` - DELETE data, status 200.
8. `08-uji-stats.png` - GET statistik, status 200.
9. `09-tampilan-desktop.png` - tampilan halaman uji pada layar desktop.
10. `10-tampilan-mobile.png` - tampilan halaman uji pada layar HP.

Kalau ingin mengambil ulang screenshot setelah mengubah kode, jalankan server
(`npm start`), lalu buka endpoint yang ingin diuji. Untuk tampilan mobile,
gunakan device toolbar di browser (F12) dengan lebar sekitar 390 px.
